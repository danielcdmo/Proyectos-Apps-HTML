☁️ Copia en la nube

Guarda tus datos solos en un repositorio privado tuyo de GitHub. Si cambias de móvil, los recuperas en un minuto.

  1. Crea en GitHub un repositorio privado, por ejemplo economia-cdmo-datos. No uses uno público: tus gastos se verían.
  2. GitHub → Ajustes → Developer settings → Personal access tokens → Fine-grained tokens. Dale acceso solo a ese repositorio, con el permiso Contents: Read and write.
  3. Pega aquí tu usuario, el nombre del repositorio y el token.
Estado
—
Cada cambio se guarda solo a los pocos segundos. En GitHub queda el historial de versiones.

El token se guarda solo en este móvil y nunca entra en las copias.

Código de bloqueo

La app pedirá un código de 4 números al abrirla y al volver tras un rato fuera. Es un bloqueo para que nadie cotillee: no cifra los datos.
